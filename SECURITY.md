# Security policy

If you find a security problem with this site or its code, please email **samuelepoma45@gmail.com** rather than opening a public issue. The same address is published in [`/.well-known/security.txt`](public/.well-known/security.txt).

Please include what you found, how to reproduce it, and the page or file it affects. I will reply as soon as I can. Only the current version of the site, the `main` branch, is supported.

The site is static: it has no server code, no forms, no accounts and no cookies. How it is protected (headers, Content-Security-Policy, dependency and secret scanning) is described in [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md#security-and-privacy).
